# metabarcoding-vs-spectrofluorescence
Datasets and R code for the manuscript titled "Comparative analysis of environmental DNA metabarcoding and spectro-fluorescence for phytoplankton community assessments"

Sequence pre-processing:
R code for pre-processing of sequence data: sequence_processing_16S.R and sequence_processing_18S.R
Mapping data files for pre-processing: mapping_eDNA1_16S.csv and mapping_eDNA1_18S.csv

Data analysis:
R code for data analyses: data_analysis_ALAmethods_eDNA.R
ASV tables: asv_table_eDNA1_16S_noNEG_vs.csv and asv_table_eDNA1_18S_pr2_mesocosms_vs.csv
Taxonomy tables: tax_table_eDNA1_16S_noNEG_vs.csv and tax_table_eDNA1_18S_pr2_mesocosms_vs.csv
Sample data: sample_data_eDNA1_16S_noNEG_vs.csv and sample_data_eDNA1_18S_pr2_mesocosms_vs.csv
ALA data: ALA1_averages.csv
Temperature data: temp_weeks_39.csv
